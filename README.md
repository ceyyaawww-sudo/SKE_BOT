# دليل تشغيل ملفات البوت

هذه الملفات جاهزة للرفع مع سورس البوت على GitHub ومن ثم استضافة Railway:

1. **`requirements.txt`**: يحتوي على المكتبات البرمجية الـ 26 المطلوبة.
2. **`Procfile`**: أمر تشغيل البوت تلقائياً (`worker: python3 main.py`).
3. **`config.py`**: ملف الإعدادات الذي يضم الأسماء (عربي وإنجليزي)، التوكن، وAPI ID، والأيدي.
